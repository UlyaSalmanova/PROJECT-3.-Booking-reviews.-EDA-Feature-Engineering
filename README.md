# Предсказание рейтинга отеля на основе отзывов

## 📌 Описание проекта

**Цель:** построить модель машинного обучения для предсказания рейтинга отеля (reviewer_score) на основе текстов отзывов, тегов, даты и географических данных.

**Датасет:** данные об отелях, включающие тексты отзывов, оценку рецензента, количество отзывов, дату, страну, координаты и теги.

**Бизнес-задача:** если предсказания модели сильно отличаются от фактического рейтинга, это может сигнализировать о том, что отель ведёт себя нечестно (например, накручивает отзывы или занижает оценки конкурентам). Такие отели стоит проверить.

**Задача:** регрессия (предсказание непрерывной величины - рейтинга отеля).

## 📊 Этапы работы

В соответствии с заданием, работа была разделена на пять этапов:

### 1. Удаление строковых значений

- Удалены все столбцы с текстовыми данными, которые невозможно преобразовать в числа

### 2. Очистка от пропущенных значений

- Пропуски в числовых признаках заполнены нулем
- Удалены полные дубликаты строк

### 3. Создание новых признаков

- Из даты извлечён квартал
- Из страны рецензента создан бинарный признак (топ-11 стран)
- Из отзывов извлечена длина и наличие негатива/позитива
- Из тегов созданы бинарные признаки: тип поездки, длительность пребывания
- Из адреса извлечена страна отеля (One-Hot кодирование)

### 4. Преобразование признаков

- Применено логарифмирование (`np.log1p`) для `neg_len` и `total_number_of_reviews`
- Удалены выбросы по IQR (межквартильному размаху) для `neg_len` и `total_number_of_reviews`

### 5. Отбор признаков

- Использован `SelectKBest` с F-статистикой
- Отобраны 12 наиболее значимых признаков

## 📊 Варианты решения

### Вариант 1. Базовый (только числовые признаки)

**Что сделано:**

- Выполнены пункты 1-2 (удаление строковых, очистка пропусков)
- Отобраны 8 лучших признаков через `SelectKBest`
- Модель: `RandomForestRegressor`

**Результат:** MAPE = 0.1435

### Вариант 2. С новыми признаками и преобразованиями

**Что сделано (дополнительно к базовому):**

- Выполнены все пять пунктов
- Добавлены новые признаки (дата, отзывы, теги, страна)
- Применены преобразования (логарифмирование, удаление выбросов)
- Отобраны 12 лучших признаков

**Результат:** MAPE = 0.1349

## 📊 Сравнение результатов

## 🧠 Выводы

- **Самый сильный признак** - длина негативного отзыва (`neg_len`), особенно после логарифмирования.
- **Наличие негативного отзыва** (`has_neg`) - важный бинарный сигнал.
- **Теги отеля** (`Leisure trip`, `Business trip`) оказались умеренно полезными.
- **Географические признаки** (`lat`, `lng`, страна) показали низкую значимость и были удалены.
- **Качество модели улучшилось** благодаря созданию новых признаков и преобразованиям.
